# KitapArsiv — Local Search

Makes the Google Sheet index (63,636 records) of a 55-library Turkish e-book
archive searchable in the browser. Find which library holds the author/book you
want, then open that Yandex Disk folder or the file page directly with one click.

## Usage

1. Double-click `ara.bat` (or open `index.html` in a browser).
2. Type an author or book title. Turkish spelling variants
   (`ı/i`, `ş/s`, `ğ/g`, `ç/c`, `ö/o`, `ü/u`) and punctuation are ignored:
   `tanpinar` ↔ `Tanpınar`, `bes sehir` ↔ `Beş Şehir`.
3. Per-result buttons:
   - **Open file** — the file's Yandex Disk preview page
   - **Folder** — the full folder of the library it belongs to
   - **Copy** — copies the file name to the clipboard (to search elsewhere)

Shortcuts: `/` focuses the search box, `Esc` clears it, `Enter` opens the first result.

### Command line

```bat
python ara.py "ahmet hamdi tanpinar"
```

## Files

| File | Purpose |
|---|---|
| `index.html` | The UI (single file, no dependencies, no server needed) |
| `data/arsiv.js` | Search index of 63,636 records (generated by build.py) |
| `data/kitaplar.csv` | Raw CSV downloaded from the Google Sheet (cache) |
| `build.py` | Re-downloads the sheet and regenerates the index |
| `yandex.html` | Yandex özel arşiv ("kitap ve kahve kokusuna aittir", ~5 bin kitap) arama sayfası |
| `data/yandex.js` | Yandex arşiv indeksi (`python build-yandex.py` ile üretilir) |
| `build-yandex.py` | Yandex paylaşım klasörünü tarayıp indeksi yeniler |
| `ara.py` | Command-line search |
| `kutuphaneler.json` | Library no. → Yandex Disk folder link |

## Refreshing the data

When new books are added to the Google Sheet:

```bat
python build.py
```

Then reload the page with `Ctrl+F5` to pick up the new index.

## Library links

Links were extracted from the Reddit posts: [E-Kitap Arşivi](https://www.reddit.com/r/secilmiskitap/comments/1k76y3m/ekitap_arsivi/) (libraries 1–50) and a [comment on the follow-up post](https://www.reddit.com/r/KutuphaneBekarlari/comments/1ukeb4w/grubun_ad%C4%B1na_yak%C4%B1%C5%9F%C4%B1r_bir_ekitap_ar%C5%9Fiv/) (libraries 1–55; 1–50 cross-checked, no mismatch).

If a new library is added, append it to `kutuphaneler.json` and run `python build.py`:

```json
"56": "https://disk.yandex.az/d/LINK"
```

## Scope

Search + deep-linking to the right file. Bulk automated downloading of the
archive (pulling all libraries) is intentionally not included; downloading stays
under your control on Yandex Disk.
